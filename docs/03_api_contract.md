# Zuum API Contract — `/api/v1/` (consumer surface)

OpenAPI 3 spec is generated by `drf-spectacular` at `/api/v1/schema/` (Phase 2).
This document is the frozen contract the Flutter apps code against.
**Consumer app = zuum_customer.** Partner/admin surfaces have their own docs.

## Conventions

- JSON only; `Content-Type: application/json`
- Auth: `Authorization: Bearer <access>` (JWT, 15 min) + `refresh` token
  (httpOnly cookie in web; secure storage in mobile). Refresh rotates.
- Pagination: `?page=&page_size=` → `{count, next, previous, results}`
- Errors: `{code, message, details?}`; HTTP codes: 400 validation, 401 auth,
  403 forbidden, 404 not found, 409 conflict, 429 rate limit
- IDs are UUIDv4 strings. Money fields are integers in paise (`*_paise`).
- Timestamps: ISO-8601 UTC.

## Auth

| Method | Path | Body → Response |
|---|---|---|
| POST | `/auth/register` | `{email, password, first_name, last_name, phone?}` → `201 {user}` |
| POST | `/auth/login` | `{email, password}` → `{access, refresh, user}` |
| POST | `/auth/refresh` | `{refresh}` → `{access, refresh}` (rotated) |
| POST | `/auth/logout` | `{refresh}` → `204` (revokes) |
| GET | `/auth/me` | → `{user}` |
| POST | `/auth/password/forgot` | `{email}` → `204` (always; no enumeration) |
| POST | `/auth/password/reset` | `{token, password}` → `204` |

`user` shape: `{id, email, first_name, last_name, phone, phone_verified, role, created_at}`

## Catalog & pricing

| Method | Path | Notes |
|---|---|---|
| GET | `/service-categories?city=blr&kind=ride\|goods` | enabled categories only |
| POST | `/pricing/quote` | see below → `FareQuote` |

`POST /pricing/quote`:
```json
{
  "kind": "ride" | "goods",
  "service_category": "sedan",
  "pickup": {"lat": 12.97, "lng": 77.59},
  "drop": {"lat": 12.93, "lng": 77.62},
  "scheduled_at": null,
  "weight_kg": null,          // goods only
  "needs_loading_help": false // goods only
}
```
→ `{id, service_category, distance_m, duration_s, breakdown:
{base_paise, distance_paise, time_paise, surge_paise, toll_paise,
waiting_paise, discount_paise, total_paise}, valid_until}`

## Routing & places (Phase 2 additions)

| Method | Path | Notes |
|---|---|---|
| POST | `/routing/route` | `{profile: auto|motorcycle|truck, waypoints:[{lat,lng}], steps}` → `{distance_m, duration_s, geometry, encoded_polyline, steps[], bbox, provider, degraded, cached}` |
| POST | `/routing/matrix` | `{profile, sources[], targets[]}` → `{durations_s, distances_m, provider, degraded}` |
| GET | `/routing/health` | provider, reachability, latency, cache TTL, circuit state (public) |
| GET | `/places/search?q=&lat=&lng=&limit=` | OSM Photon → Nominatim, cached; `{results:[{name,address,lat,lng}], provider}` |
| GET | `/places/reverse?lat=&lng=` | Reverse geocode with the same providers |

Quote responses add `route { geometry, provider, degraded }`; bookings add
`route { geometry, steps, provider, degraded, distance_m, duration_s }` and the
customer trip `otp`. `GET /bookings/{id}/route?leg=drop|pickup` returns the
stored route or a fresh driver-approach route. See
[ADR-002](07_maps_routing.md) for fallback and attribution policy.

## Bookings

| Method | Path | Notes |
|---|---|---|
| POST | `/bookings` | `{quote_id, pickup, drop, payment_method, promo_code?, ...}` → `201 booking` |
| GET | `/bookings?status=&page=` | own bookings, newest first |
| GET | `/bookings/{id}` | includes driver, vehicle, status history tail |
| POST | `/bookings/{id}/cancel` | `{reason}` → transition; fee applies per stage |
| POST | `/bookings/{id}/rate` | `{rating, comment?, tags?}` → `201` (post-completion only) |
| GET | `/bookings/{id}/receipt` | itemized receipt (PDF-ish JSON for now) |

`booking` shape:
```json
{
  "id": "uuid", "type": "ride|goods", "status": "SEARCHING",
  "service_category": {"code": "sedan", "kind": "ride", "name": "Sedan"},
  "pickup": {"lat": .., "lng": .., "address": ".."},
  "drop": {...},
  "fare": {"quoted_paise": 0, "final_paise": null, "currency": "INR"},
  "payment_method": "cash|upi|card|wallet",
  "payment_state": "unpaid|paid|refunded|failed",
  "scheduled_at": null, "created_at": "..",
  "driver": null | {"id", "name", "phone", "rating_avg", "photo_url"},
  "vehicle": null | {"registration_number", "make", "color", "category"},
  "trip": {...} | null,
  "shipment": {...} | null
}
```

Goods booking extra (on create): `goods_type, weight_kg, dimensions_cuft,
needs_loading_help, sender{name,phone}, receiver{name,phone}, stops[]`.

## Rate limits (initial)

- `auth/*`: 10/min per IP
- `pricing/quote`: 30/min per user
- `bookings` write: 20/min per user
- `safety/sos`: no limit (audited)
